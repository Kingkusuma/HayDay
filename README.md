# HayDay
# Prototype V1
ใช้เซ็นเซอร์ TCS34725 ต่อเข้ากับบอร์ด ESP32 ในการจำแนกและนับสินค้า โดยการแยกสี RGB ของแต่ละชิ้นงาน
จุดด้อยของPrototepe V1 ด้วยความที่ใช้เซ็นเซอร์ TCS ตัวเดียวทำให้เซ็นเซอร์อ่านค่าสีตลอด แม้ไม่มีชิ้นงาน แสดงผลที่นับได้ผ่าน Serial monitor



# Prototype V2
จากข้อด้อยของ V.1 เราได้พัฒนาโดยเพิ่ม IR Sensor มาแก้ปัญหาที่เกิดจากตัว TCS เนื่องจากตอนแรกใช้เซ็ฯเซอร์ตัวนี้ในแยกทั้งสีสินค้าและนับสินค้าไปพร้อมกัน ทำให้ตัวเิซ็นเซอร์ทำงานหนักจนเกิดไปและอ่านค่าผิดพลาด จึงจำเป็นต้องเพิ่ม IR Sensor เ้ข้ามาเพื่อที่จะให้ IR มาตรวจจับสินค้าก่อน แล้วค่อยให้ตัว TCS อ่านค่าสีเมื่อตรวจพบชิ้นงาน แล้วจำแนกสีแสดงผ่าน Dashboard เพื่อดูผล
